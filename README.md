# Rock Paper Scissors in C

A simple Rock-Paper-Scissors game developed using C.

## Features

- Player vs Computer
- Random computer selection
- 3 rounds
- Input validation
- Score tracking

## Concepts Used

- Arrays
- Strings
- `strcmp()`
- `rand()`
- `srand()`
- Loops
- Conditional statements
- Functions from `stdlib.h`, `string.h`, and `time.h`

## How to Run

Compile:

```bash
gcc rock_paper_scissors.c -o game
